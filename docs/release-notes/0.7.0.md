Version 0.7.0 restores the original opening and menu flow, gives LAN and Internet
the same short setup, and adds asset mods that the normal launcher remembers.

Watch the [0.7.0 menus and mods demo](https://www.youtube.com/watch?v=kdETJWSwXpA).

## Menus and multiplayer

- Main-menu **LAN** and **Internet** entries replace the separate network Start
  and Join entries. Both use the original artwork, fonts, player rows and shared
  arena preview.
- Host setup shows game type, ten colored player rows and connected node names.
  Unused rows start OFF and accept connections. The host can assign AI, close a
  row, switch teams or release a player without disconnecting its computer.
- Player controls follow the original cycle: Left turns a player OFF; Right
  selects AI before local keyboard/controller controls on the host. Clients
  choose their own controls and identify other players by node nickname.
- Enter advances from players to the arena and victory target, then starts the
  match. The optional **Options** screen has one Scheme File selector and the
  other battle rules. Clients follow the host's preview and rules.
- Host preferences save separately from local-game preferences. Multiple app
  windows sharing one profile preserve each other's changes, including when a
  stale client saves or closes after the host.
- A client leaving a paused match no longer ends the session. After the normal
  five-second grace, AI takes over and its avatar moves and animates correctly
  on the host and remaining clients.
- Escape navigates back or pauses/resumes play; it does not quit from the main
  menu. Opening logos, title/menu audio, results and F1 help follow the restored
  flow and explain the current LAN/Internet controls.
- Enclosure settings expose the original None, two-row, four-row and
  all-the-way choices. Sparse player rows retain their original colors and
  starting positions.

## Asset mods

Choose **Options → Mods → Choose mod folder → Apply and restart**. Later launches
from the normal application, Dock icon or shortcut remember that folder.
**Use original assets → Apply and restart** switches back.

Original `.RSS`, `.PCX`, `.ANI`, `.FON`, `.SCH`, resource and remap files override
the base game. Missing files retain the base asset, and a separate cache leaves
both source folders unchanged. Empty recordings remain intentionally silent;
the audio mixer handles empty looping clips without hanging or retaining voices.
Modded and unmodded players can share a room: the host supplies the map and rules,
while each player keeps their own artwork and audio.

`--mod <directory>` supplies a temporary override. `--no-mod` ignores the saved
choice for one launch. An unavailable remembered folder produces an error and
opens the original assets so another folder can be selected. See the
[mod guide](https://github.com/andrei-ace/atomic_bomberman/blob/v0.7.0/README.md#asset-mods)
for animation/palette requirements.

## Upgrade and downloads

**Update the relay and all clients together.** This release uses protocol 8
(`ABG8`, QUIC ALPN `atomic-bomberman/8`, compatibility family `0.7.0`). Protocol-7
builds, including 0.6.1, are incompatible and display a version error. Existing
server links, access tokens, TLS identities, settings and imported data remain
valid. The owner-authoritative movement model and 100 ms provisional window are
retained.

- Windows x64 portable ZIP: Windows 10 22H2 or Windows 11; unsigned.
- Apple Silicon Mac ZIP: macOS 11 or newer; ad-hoc signed, not notarized.
- Linux x86-64 AppImage: Ubuntu 24.04 or newer, X11/XWayland.
- Linux ARM64 and amd64 relay archives: glibc 2.39 or newer.

All five packages include source provenance and SHA-256 checksums. Original game
data and private server configuration are excluded; import your own game data
on first launch. Internet play requires TCP and UDP 443. LAN hosting requires
TCP/UDP 1997. Follow the
[installation and play guide](https://github.com/andrei-ace/atomic_bomberman/blob/v0.7.0/README.md).
