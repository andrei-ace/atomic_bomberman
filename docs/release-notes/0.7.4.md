# 0.7.4

- Restore the original scoreboard and arena alignment in Classic and HD. The
  board, background and HUD share the original canvas, removing the extra gray
  gap and the narrower battlefield. Scores use the original font, palette
  colors and elimination markers; the timer uses its original animation art.
- Fill widescreen sides with matching arena or menu scenery while preserving
  the complete board and sprite proportions. Resize the window or use fullscreen;
  the presentation adapts automatically. Decorative areas do not accept clicks.
- Remember the last windowed size between launches. Fullscreen dimensions and
  transition frames do not replace it, including on macOS when the native green
  window button changes fullscreen. Existing profiles keep the default size
  until the window is resized.
- Fix translucent HD edges darkening when the completed scene is presented to
  the window. Scene rendering now preserves opaque destination coverage with
  separate alpha blending, including the Metal backend. The shaders retain the
  original textured-color calculation.
- Preserve mod overrides for HUD positions, active font/marker animations and
  RMP/palette colors. Retain the original color percentages during import and
  palette overlays without changing the identity of matching HD artwork.

Completed HD packs, imported assets, mods, settings and private server links
remain usable. No new HD preparation is required. The enhancement format,
protocol 8 and the 0.7.0 compatibility family are unchanged; compatible Classic
and HD clients continue to share LAN and internet games.

Native layout checks execute isolated original routines and compare rendered
Classic/HD pixels with the original or prepared assets. Local macOS checks cover
4:3, 16:9, ultrawide and portrait presentation, missing-cache fallback, retained
HD files and window-size restoration across fresh launches. These checks do not
certify physical input/audio or other platforms' graphics hardware. See the
[layout verification](../render-alignment.md#hud-and-window-layout).
