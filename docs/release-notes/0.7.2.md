# 0.7.2

- Optional HD graphics enhance the installed artwork locally at 4× and render
  at the physical display viewport's resolution. Classic remains the default.
- Graphics preparation has progress and cancellation; unavailable or failed HD
  rendering falls back to Classic with a reason and Retry.
- HD preparation uses resource-bounded parallel asset workers, calibrates GPU
  throughput, and retries unfinished work with one worker if parallel inference
  fails. Available-memory checks reduce work under pressure.
- HD follows active graphical, font and palette mods. Voice/scheme-only mods
  reuse unchanged HD artwork, preserving intentional silent recordings.
- Switching to Classic keeps completed HD artwork on disk; selecting HD again
  reuses the matching cache. README preparation timings distinguish measured
  M4 Pro results from the full parallel estimate.
- Graphics can import a matching HD folder from another computer and export a
  portable HD folder. Transfers validate all pages and support cancellation.
- The battle HUD restores the original-style gray bar, colored score/kill
  counters, elimination crosses and large timer.
- The main menu uses the original striped green trigger-bomb cursor with its
  original animation selection and unmodified colors.
- README credits acknowledge the runtime, enhancement and reconstruction tools.
- Security dependencies use patched `rustls` 0.23.46, `time` 0.3.47 and
  `rand` 0.8.6, addressing the seven currently reported Dependabot alerts.
- The HD-tool ZIP reader uses patched `zip` 9.0.5, including the
  [dual-header parsing fix](https://github.com/advisories/GHSA-m665-v7pm-7grj).
  Tokio 1.51.6 includes the upstream AsyncFd safety fix found during the wider
  dependency audit.

The network protocol and compatibility family remain unchanged.
