# 0.7.5

- Support Ubuntu 22.04 and newer, plus compatible x86-64 Linux distributions
  with glibc 2.35 or newer and X11/XWayland. The AppImage's launcher, game,
  helpers and bundled libraries are built on Ubuntu 22.04.
- Fix startup with newer Mesa/LLVM graphics drivers by using the system's
  GCC/C++ runtimes alongside its graphics drivers.
- Rename the Linux download to `atomic-bomberman-0.7.5-x86_64.AppImage`, with
  matching checksum and build-manifest names.
- Check the same AppImage on Ubuntu 22.04, 24.04, 26.04 and Debian 12, then run
  AppImageHub's unchanged catalog checker before publication. Packaging and
  release verification reject bundled ELF requirements above glibc 2.35.

Ordinary AppImage startup continues to work without FUSE. Original game data,
completed HD packs, mods, settings and private server links remain usable.
Protocol 8 and the 0.7.0 compatibility family are unchanged; compatible existing
clients and relays can continue playing together. Physical graphics, audio and
controller hardware are separate from the automated software-rendering checks.
